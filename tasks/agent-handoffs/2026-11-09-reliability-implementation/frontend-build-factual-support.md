## Actual behavior

Every replacement passes current whole-document LaTeX admission and the common factual-support guard, regardless of mode. Exact source offsets/original selection remain bound. Unsafe or unproved factual changes return advice with null replacement and a fixed non-presupposing question. Candidate confirmation does not turn an unsupported change into an applicable patch. Resume retains the existing explicit confirmation requirement after a supported patch; the pure Apply helper still refuses a forged false confirmation flag.

Explanations and questions are checked independently of replacement safety, including advice and no_change operations. The finite allowlist controls which raw nonfactual editorial/syntax descriptions and neutral evidence questions may be retained; it does not require the model to use exact words to obtain a safe edit. Unvalidated prose is discarded and replaced with a fixed nonfactual server explanation. A separately supported replacement is retained. Model questions remain unresolved uncertainty and still withhold a replacement; unsafe questions become a fixed neutral source question. No raw invented employer, leadership, impact or presupposing question survives the fallback. Advice/no_change outputs receive safe guidance too. This is not semantic certification of arbitrary free-form model prose.

The new reader is a typed, closed structural subset; it never executes TeX or expands a macro. It handles literal text, escaped literal symbols, grouping and known text/style wrappers; finite font declarations; typed fontsize/hspace/vspace arguments; article metadata and the named standard package subset; section/item/document/list/center/alignment structure; and literal URL/href destinations/labels. Logical structure and literal payload stay ordered. Structural event kind/start/end positions are bound to the canonical projected text in Unicode code points; a heading, paragraph or item cannot be moved while retaining only the same unpositioned command names. Visibility-affecting color wrapper names/arguments and their exact projected payload boundaries must remain invariant. Introducing white text, changing the color or moving its scope yields advice; known bold/style formatting within an unchanged color scope remains possible. Business numbers, units, signs, identities and links are literal payload; bounded font-size/dimension arguments are technical values rather than business metrics.

Fontsize arguments are 1–96 with at most two decimals and optional pt; documentclass size options are 10/11/12pt. Dimensions have bounded signed numeric grammar and known units. Nesting is capped at 24, including environments; combined parts/structure tokens at 8,192. Request/replacement byte/character, selection, payload, timeout and compiler limits remain unchanged. Exact known closing-group repair at the selected EOF is limited to eight missing closers; it cannot rescue an arbitrary quotation prefix or remove a semantic suffix.

Known formatting with the same canonical literal text and logical structure can pass without inventing a prose transformation. This retains genuine braces, wrapper/style and font-size changes, including formatted measurement units. Where visible prose changes, the reader projects the full local source and exact selection into the actual writing-support 1.0.3 document. The existing source-bound rewrite assessor must support the complete selected claim with its surrounding qualifiers; the IR is not built from an isolated selection. Preceding colleague/never scope, later unresolved qualification and context beyond the provider's two-line window remain authoritative.

Unknown commands, definitions/redefinitions, unsupported environments/options, arbitrary math syntax or ambiguous source projections yield advice. No regex removes unknown TeX to manufacture evidence. Comment content stays structurally protected; nonempty comments withhold prose transformations instead of silently discarding possible context. The known package set is amsmath/amssymb/amsfonts/latexsym/geometry/hyperref/enumitem/xcolor/titlesec. Supported AI proof is narrower than compiler syntax; manual editing and compiler support are unchanged. The contract preserves source text/relationships under this finite projection, not general TeX equivalence, visibility/render parity, candidate truth, artifact verification or ATS performance.
