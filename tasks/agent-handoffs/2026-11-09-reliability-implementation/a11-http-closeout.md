`POST /analysis/:id/author/typed` checks method, all three flags, origin and session identity before creating a privileged client. The owner comes from the session. Private/no-store/noindex JSON replies preserve cookie refresh headers. Native forms have a 64 KiB body cap and five-second read/parsing budget; duplicate/unknown/file fields, duplicate JSON keys and oversized commands are refused. Errors contain only fixed reason/recovery codes, never raw submitted data or provider errors.

Preview explicitly uses a local equivalent-word rule, not an AI model. It calls the existing bound producer with current owned inputs and a second fresh read. Decision sends the exact original command through the typed repository and new atomic RPC capability. Native execution remains denied independently of the HTTP flag. Acknowledgements are fresh visible form inputs; they do not prove independent human review.

Undo checks the owner-filtered immutable accepted event, original command/hash, exact recorded receipt, original base and accepted canonical version. Only the replay receipt's idempotent bit may differ. The existing undo/CAS path runs against the exact accepted version and retains one undo key across ambiguous retries; it never substitutes a later head. Typed acceptance remains two immutable children, rejection creates no child, and undo creates a new version.

The score loader offers this workspace only for consistent current owned typed inputs. Historical, disabled or mismatched inputs keep readable diagnostics without actions. Unknown/incomplete source pages may expose an explanation-only workspace; every target is noneditable and the actual preview endpoint refuses it. The two initially overstrict workspace-null assertions were replaced under [explicit Root review](a11-http-page-assertion-review.json) with stronger binding, target, null-number and no-write checks. Original failures remain preserved.

The client retains exact commands in page memory, sends no payload in URLs/storage/logs, correlates response/action/key/version fields and revalidates only confirmed replies. The server owns full A11OP1 digest validation. A 30-second deadline covers fetch and response draining; the streamed response is capped at 128 KiB before decoding. Temporary or ambiguous saves retain manual exact retry without automatic resubmission. Real stalled fetch/body and server read/cancel failures were reproduced and repaired; a temporary body-timeout recovery regression was also preserved and fixed. Setup failures are labelled separately from product REDs.

`TYPED_AUTHORING_ENABLED` defaults false, with scoring and authoring flags also required by the callers.
