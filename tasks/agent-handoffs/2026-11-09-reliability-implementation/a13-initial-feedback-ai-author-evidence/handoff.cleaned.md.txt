# A13 dedicated raw AI boundary

Implemented only the new raw SDK boundary and its independent unit file. It does not call either legacy lossy transport/helper, ground prose, assess support, compile a plan, dispatch through a native operation, or publish content. Raw unsupported assertions deliberately remain in the observation until the caller's actual compiler assesses the complete resolved generation once.

`createInitialFeedbackRawTransport(config,{fetch?,now?})` returns an execute method taking originalSource, jobTitle, jobDescription, idempotencyKey, optional signal and required onObservedUsage. Its result is `{raw,rawResponseSha256}`: raw is exactly `initial-feedback-raw/1.0.0` with output/refused/finishReason/usage. The separate nullable hash covers exact received message.content UTF8, including whitespace, or is null when those bytes cannot be represented faithfully. It is never a JSON.stringify reconstruction hash or native proof.

The installed SDK makes one request with retries0, storefalse, n1, streaming disabled, redirecterror and logging off/silent logger. Existing egress/model helpers are reused; API key and SDK organization/project/admin/webhook options are explicit, with no selected env-file loader. The attempt bounds SDK fetch, streamed body and observer with the same deadline. Candidate JSON is limited to 65,536 bytes; outer response is 1MiB; original source is 100,000 UTF16 units and constructed input is 4MiB. Unknown/duplicate JSON keys, malformed Unicode and invalid generation shapes are rejected without raw content in errors.

Safe known/null usage is saved locally before awaiting the observer, which runs before candidate parsing/refusal or reference rejection. It remains on fixed failures when the observer throws or the request is cancelled. Unknown is null, including malformed/missing counters, never invented zero. Genuine zero counters are preserved. The caller remains responsible for technical settlement and native known/held-unknown admission before compilation/publication; returning a raw null-usage capture does not authorize either.

`resolveInitialFeedbackGeneration(originalSource,capture)` uses actual buildRewriteSources, validates the strict generation and preserves category/writer order and text. Every writer ID resolves to its exact original quotation. Unknown or duplicate IDs refuse the entire generation; nothing is dropped or invented. It also applies Unicode/64KiB checks to direct capture inputs. `InitialFeedbackAiFailure` exposes only fixed code, safe usage and nullable strict GenerationFailure; failures never fabricate a QualitativeSupport observation.
