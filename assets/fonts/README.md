# Bundled renderer fonts

Noto Sans is the default font. Noto Sans Math supplies mathematical glyphs missing from the default font. Both fonts are embedded locally; rendering does not fetch fonts.

Both files come from the Noto project and use the SIL Open Font License in [OFL.txt](OFL.txt).
