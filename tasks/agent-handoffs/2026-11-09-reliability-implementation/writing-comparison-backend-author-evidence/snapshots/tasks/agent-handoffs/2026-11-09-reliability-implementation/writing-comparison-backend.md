# CR-A14 writing comparison backend

Implemented browser-safe projected and saved writing observations in `app/lib/writing-comparison.ts`. Runtime imports are the existing writing-quality helper and browser dependency Zod; server canonical types are type-only imports. The actual `loadCanonical` comparison branch derives saved observations from its already-loaded owned other/current rows and retains the full raw `compareCanonical` output. Other branches return `writingComparison:null`. No extra RPC, provider or write is added.

Saved labels require matching owner, resume, organization, analysis, input hash, evidence version, retention policy and loaded source identity. Actual version IDs and revisions describe the selected direction, including reverse and same-version comparisons. Up to 50 changed-fact observations retain the original comparison order, total and remaining count. Wording, record-only metadata, additions and removals remain distinct. Existing comparison semantics omit location-only changes, so these are not manufactured as changed facts.

Projected wording always has a null saved version, `not_saved` state, and no inherited after-source count or confirmation. Exact existing writing warnings and Unicode word counts remain observations. A warning can disappear because a fact was removed; that is not a quality gain, factual verification, qualification, JD coverage delta or accepted AI transition. All score/delta fields are null and qualification credit is not assessed. Existing quality-helper semantics and canonical write/CAS/undo/history/flags/scorer remain unchanged.
