# Verified core artifacts

Status: AA6 local engineering implemented and verified under ADR-0015/E-006; formal Gate AA6 remains open.

The private export workspace at `/analysis/:id/export` reads the current immutable canonical resume. It builds one ordered presentation plan for semantic HTML, PDF and DOCX. The plan contains confirmed facts, section anchors, safe URLs, canonical version, content hash and template/renderer versions. Template code cannot write canonical content. Facts with the same type and exact value that are unassigned to sections can share one visible block while retaining both fact IDs in the plan. Unassigned confirmed facts are placed in their matching semantic section when available; remaining facts stay visible. Divergent bullet prose, uncertain facts, unsafe links, unsupported locales/glyphs and oversize inputs stop export before rendering.

A disposable worker renders the selected PDF or DOCX under a 10-second wall limit, 128 MiB old-generation heap limit, 30,000-character plan limit, 5 MiB output limit, 10-page policy and two concurrent jobs per server process. The template uses A4 or US Letter and a bundled SIL OFL Noto Sans font. PDF uses ordered structure tags and an embedded font. DOCX uses OOXML headings, embedded font and external hyperlink relationships. DOCX pagination is an estimate and the user is told to inspect its flow in a viewer. Renderer input is data only; there is no user HTML, TeX, shell command, remote font or fetched link.

Independent PDF.js or OOXML extraction reads the generated bytes. Verification compares critical fields, exact normalized text, reading order, section headings, link targets and labels, layout/page/font checks and structural signals. A failed attempt has `export_verification_failed` state and no byte response. The browser first requests a check report, then downloads through a separate POST that rechecks owner, source/deletion status, saved head version and parse-back. Responses are private and uncached. Artifacts and reports are not persisted; each download is regenerated. The checked action preserves a no-JavaScript form path.

Enable `CANONICAL_AUTHORING_ENABLED=true` and `ARTIFACT_RENDERING_ENABLED=true` in a local test environment with Supabase running, then open the analysis export link after confirming the canonical facts. The flag is false by default. Use `npm run test:aa6:local`, `npm run benchmark:render-parity` and `npm run test:e2e` against isolated local fixtures. No hosted database migration is needed for transient artifacts.

The verified label means this artifact passed this template's machine parse-back checks. It is not a PDF/UA, screen-reader, viewer-matrix or employer-ATS certification. Formal release requires approved viewer and assistive-technology review, representative domain/locale corpus, security/accessibility owner acceptance and upstream gate resolution. PDFKit's current structure limitation for link annotations is described in its [accessibility guide](https://pdfkit.org/docs/accessibility.html).
