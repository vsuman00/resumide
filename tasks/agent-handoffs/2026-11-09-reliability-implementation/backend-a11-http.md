`POST /analysis/:id/author/typed` requires all three scoring, authoring and typed-authoring flags. Method, flags, origin and session authentication precede body admission and privileged client creation. Session identity supplies the owner. Responses are strict JSON with private/no-store and noindex/nofollow headers; session cookie refresh headers are retained. Unsupported methods return 405 with Allow POST, foreign origins 403, missing authentication 401, disabled flags 404, oversized bodies 413, unsupported media 415, invalid input 422, stale inputs 409 and unavailable operations 503. Errors expose only fixed reason/recovery values and never echo submitted commands or raw errors.

`readTypedAuthoringHttpForm` accepts native URL-encoded or multipart text forms. It rejects duplicate decoded outer fields, unknown/file fields, duplicate decoded JSON keys, excess JSON depth/tokens, commands over 16 KiB or the A11 framing limit, and bodies over 64 KiB. The body has a five-second whole-read/parsing deadline, absolute deadline checks and request-abort handling. Cancellation is observed without waiting on an untrusted cancellation promise; cleanup preserves the primary error, including 413. Temporary body deadline/abort failures return retry-exact recovery. The optional timeout test seam is not a form field.

The exact forms are preview with selection JSON; decision with command JSON and `reviewAcknowledgement=accepted` only for acceptance; and undo with accepted receipt JSON plus a fresh UUID idempotency key. Reject forms must omit acknowledgement. Success envelopes are proposal, applied and undone. Undo returns the validated legacy undo receipt and the submitted undo key separately as correlation data.

Preview uses an explicitly named local editorial rule, not an AI provider. Its fixed Built -> Created -> Developed -> Built selection goes through the actual owned preflight, bounded producer, writing-support check and second fresh owned read. It returns the real generated command pair. Decision uses `applyTypedAuthoring` with a server-only capability wrapping the actual four-argument `apply_typed_authoring_action` RPC. Flags do not grant SQL authority: the native writer remains denied and unactivated, and an unavailable result is not reported as a save.

Undo first loads the exact accepted canonical version through the owned repository, then reads the exact owner/analysis-filtered authoring event. `validateTypedUndoEvent` checks the complete recorded command/hash, receipt, owner/org/resume/source/attempt, actual version/revision, event ID and original base. Only the idempotent receipt bit is normalized for replay comparison. It then calls existing `applyAuthoring` undo with expectedVersionId equal to the accepted version and the fresh caller key. No current head is substituted. The response must be an undo receipt at accepted revision plus one with a fresh result version. Existing CAS, ownership, privacy, immutable history and exact retry behavior remain authoritative.
